# 榫卯结构设计与装配推演台

浏览器内的实木家具榫卯设计与装配推演系统：TypeScript + three.js，数据存 IndexedDB，无需后端。

## 启动

```bash
npm install
npm run dev      # 开发
npm test         # 核心算法单测（14 项）
npm run build    # 生产构建（tsc 严格检查 + vite 打包）
node scripts/smoke.mjs   # 无头浏览器全链路冒烟（需 dev server 在 5180 端口）
```

首次启动若 IndexedDB 无数据，自动生成「明式圈椅」（18 构件 / 25 节点）与「带抽屉方桌」（15 构件 / 17 节点）。

## 六大页面

| 页面 | 能力 |
| --- | --- |
| 款式列表 | 增删改复制、JSON 款式包打包导出/导入 |
| 构件编辑 | 木料截面/长度/中心坐标、材种、木纹方向（纹理顺木纹贴） |
| 榫卯库 | 燕尾/格肩/抱肩/粽角四类，选两构件自动布尔开榫；榫头尺寸驱动卯眼联动，配合间隙独立可设；可停用卯眼做故障演练 |
| 装配推演 | 自动求解装配顺序、锁死核报告、爆炸拆装动画、平面剖切（剖面斜线）、实时干涉标红、步骤拖拽调序 |
| 说明书 | 逐步骤线稿图 + 零件表，导出 PDF 或 PNG 图集 zip |
| 设置 | 默认间隙、爆炸间距、干涉阈值，IndexedDB 数据管理 |

## 架构

```
src/
  core/               纯算法层，零 DOM 依赖，node 可直接测
    math3d.ts         向量/AABB/扫掠体工具
    solids.ts         装配感知实体：原料箱减卯眼腔体的六板片布尔
    joints.ts         榫卯库规则、插入轴推导、接触面计算、参数校验
    assembly.ts       装配求解器：六方向扫掠贪心剥离 + 锁死核报告 + 爆炸位移
    interference.ts   AABB 粗筛 + 合法咬合扣除 + 构件版本增量缓存
    geometry.ts       three-bvh-csg 真实布尔几何 + 程序化木纹贴图
    seed_chair.ts     内置圈椅
    seed_table.ts     内置带抽屉方桌
  data/
    db.ts             IndexedDB 封装
    store.ts          发布订阅状态、款式 CRUD、求解/干涉联动
  ui/
    viewer.ts         three.js 视图：CSG 渲染、爆炸缓动、剖切、射线拾取、线稿截图
    pages/            六个页面 + 共享 viewer 宿主（跨页复用实例，不重建）
```

## 关键设计

**装配可行性 = 反向拆卸可行性。** 每根构件的实体表达为原料方箱减去自身全部卯眼腔体；对候选构件沿六个世界轴方向做无穷远扫掠，与剩余构件实体箱求交——六向全挡即不可拆。每轮贪心剥离当前可拆件（连接数少的优先，同票按 id 保证确定性），剥离序列反转即装配序列，插入方向与抽出方向同轴反向。全部构件剥不动时输出锁死核：每根构件六方向的阻挡构件明细，配合卯眼停用等配置错误一并报告。

**干涉检查按构件版本增量缓存。** 原料箱 AABB 粗筛配对，节点合法咬合体积（榫头在卯眼内的占用区域）从交叠中扣除，剩余残块按最短轴厚度给穿透深度与中心坐标。单件改尺寸只使该构件参与的配对缓存失效，其余走缓存。

**几何与求解双轨。** `solids.ts` 的轴对齐箱布尔服务实时求解（微秒级、确定性），`geometry.ts` 的 three-bvh-csg 服务可视化真实开榫（Brush 按参数缓存），两者共用同一套节点参数，保证所见即所算。

## 需求验证结果

- 圈椅、方桌均推出完整可装顺序，14 项单测全绿（含逐步扫掠路径无碰撞校验、结果确定性、锁死报告、卯眼停用故障注入、手动乱序定位失败步）
- 干涉正确设计零误报；穿模给出穿透深度与坐标；增量检查与完整求解均实测 < 200ms
- 无头浏览器冒烟覆盖六页导航、穿模联动标红、卯眼停用锁死提示、爆炸动画，无控制台错误
